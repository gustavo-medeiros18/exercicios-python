# Lista de Exercícios em Python

## 1. Sintaxe Básica e Tipagem Dinâmica

- [x] Fácil: Crie uma função que receba dois números e retorne a soma.
- [ ] Médio: Escreva uma função que receba uma string e retorne um dicionário com a contagem de cada caractere.
- [ ] Difícil: Crie uma função que valide se uma expressão matemática em string tem os parênteses corretamente balanceados.

---

## 2. List Comprehensions

- [x] Fácil: Dada uma lista de números de 1 a 10, crie uma nova lista com o quadrado de cada número.
- [ ] Médio: Filtre de uma lista de strings apenas aquelas que começam com a letra "a" (minúscula).
- [ ] Difícil: Gere todas as combinações possíveis (tuplas) entre dois conjuntos de listas, usando list comprehension.

---

## 3. Manipulação de Dicionários

- [ ] Fácil: Crie um dicionário com chaves de 1 a 5 e valores sendo o dobro da chave.
- [ ] Médio: Faça um programa que conte quantas vezes cada palavra aparece em uma frase.
- [ ] Difícil: Dado um dicionário de alunos e suas listas de notas, crie uma nova estrutura que contenha apenas os alunos com média acima de 7.

---

## 4. Funções e *args / **kwargs

- [ ] Fácil: Crie uma função que receba uma quantidade variável de números e retorne a soma.
- [ ] Médio: Crie uma função que aceite qualquer número de argumentos nomeados (**kwargs) e imprima cada chave e valor.
- [ ] Difícil: Crie um decorator que meça o tempo de execução de uma função qualquer.

---

## 5. Geradores e `yield`

- [ ] Fácil: Implemente um gerador que produza os primeiros `n` números pares.
- [ ] Médio: Crie um gerador que percorra uma string e devolva apenas as vogais uma a uma.
- [ ] Difícil: Faça um gerador que leia um arquivo de texto muito grande linha por linha, mas só retorne linhas que contenham uma palavra-chave específica.

---

## 6. Manipulação de Arquivos

- [ ] Fácil: Escreva uma função que crie um arquivo de texto com uma frase passada como argumento.
- [ ] Médio: Leia um arquivo de texto e conte o número total de palavras.
- [ ] Difícil: Faça um script que percorra todos os arquivos `.txt` de um diretório e crie um resumo com o número de linhas, palavras e caracteres de cada arquivo.

---

## 7. Classes e Orientação a Objetos

- [ ] Fácil: Crie uma classe `Pessoa` com atributos `nome` e `idade` e um método para exibir esses dados.
- [ ] Médio: Implemente uma herança simples: uma classe `Funcionario` que herda de `Pessoa` e tem um método `calcular_salario`.
- [ ] Difícil: Crie uma classe `Banco` que controle múltiplas contas bancárias, permitindo depósitos, saques e transferências entre contas.

---

## 8. Exceptions e Tratamento de Erros

- [ ] Fácil: Escreva uma função que trate a divisão por zero e retorne uma mensagem amigável.
- [ ] Médio: Faça uma função que abra um arquivo, leia o conteúdo e trate a exceção caso o arquivo não exista.
- [ ] Difícil: Implemente uma função que leia um JSON e valide campos obrigatórios, lançando exceções customizadas para campos faltantes.

---

## 9. Uso de Módulos / Importações

- [ ] Fácil: Importe o módulo `math` e calcule a raiz quadrada de um número.
- [ ] Médio: Crie um módulo Python com funções de conversão de temperatura (Celsius ↔ Fahrenheit) e importe-o de outro arquivo.
- [ ] Difícil: Crie um pacote Python com dois módulos interagindo entre si: um módulo de operações matemáticas e outro de estatísticas básicas.

---

## 10. Iteradores Customizados (Implementação de `__iter__` e `__next__`)

- [ ] Fácil: Crie uma classe iteradora que conte de 1 a `n`.
- [ ] Médio: Crie um iterador que percorra uma lista, mas pule elementos duplicados.
- [ ] Difícil: Implemente uma classe iteradora que percorra um arquivo CSV linha por linha, retornando cada linha como dicionário (header → valores).

---
